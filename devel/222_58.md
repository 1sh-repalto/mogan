# [222_58] Fix Chinese translation for 'affiliation'

### What
Added the Chinese translation for "affiliation" in the primary Chinese dictionary `zh_CN.scm`.

### Why
The menu item "Affiliation" in the author data menu (`Insert -> Title -> Author`) was not translated into Chinese, leading to an inconsistent UI experience for Chinese users.

### How
In `TeXmacs/plugins/lang/dic/en_US/zh_CN.scm`:
1. Added the translation:
```diff
+("affiliation" "单位")
```
2. Inserted the entry after `("address" "地址")` to maintain alphabetical order.

## How to test
1. Open Mogan Editor.
2. Ensure the language is set to Chinese.
3. Navigate to `插入 -> 标题 -> 作者` (Insert -> Title -> Author).
4. Verify that "Affiliation" is now translated as "单位".
